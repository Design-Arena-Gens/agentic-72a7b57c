# Iranian Marketplace Analytics Tool

## ابزار تحلیل و جمع‌آوری داده از بازارهای آنلاین ایران

یک ابزار پیشرفته برای جمع‌آوری، تحلیل و رتبه‌بندی محصولات از فروشگاه‌های اینترنتی ایرانی.

## ویژگی‌ها

### 1. ماژول جمع‌آوری داده (Web Scraping)
- پشتیبانی از فروشگاه‌های ایرانی (دیجی‌کالا، باسلام، ترب، اسنپ‌مارکت و...)
- استخراج خودکار اطلاعات محصول شامل:
  - عنوان محصول
  - قیمت
  - تصاویر (با قابلیت دانلود)
  - توضیحات
  - تعداد بازدید
  - تعداد فروش
  - امتیاز و نظرات
  - برند
  - تاریخ درج

### 2. سیستم دسته‌بندی هوشمند
- ساختار درختی دسته‌بندی‌ها
- دسته‌بندی‌های اصلی:
  - لوازم خانگی
  - لوازم الکترونیک
  - مد و پوشاک
  - زیبایی و سلامت
  - ورزش و سفر
  - کتاب و لوازم تحریر
  - اسباب بازی
  - خودرو و موتورسیکلت

### 3. ماژول تحلیل و رتبه‌بندی
- تحلیل عناوین پربازدید
- تحلیل رفتار خرید
- تحلیل روند (محصولات پرفروش، در حال رشد، رو به کاهش)
- توزیع قیمت
- برندهای برتر
- کلمات کلیدی پرتکرار

### 4. داشبورد کاربری
- نمایش نمودارهای تحلیلی
- فیلترهای پیشرفته (قیمت، برند، محبوبیت، تاریخ)
- لیست محصولات با جزئیات کامل
- ابزارهای کپی و خروجی

### 5. ابزارهای خروجی
- خروجی Excel
- خروجی CSV
- خروجی JSON
- کپی به کلیپ‌بورد
- دانلود تصاویر (تکی یا گروهی)

## تکنولوژی‌های استفاده شده

### Frontend
- **Framework**: Next.js 14 (React)
- **Styling**: Tailwind CSS
- **Charts**: Recharts
- **Icons**: Lucide React
- **TypeScript**: برای Type Safety

### Backend
- **API Routes**: Next.js API Routes
- **Scraping**: Cheerio, Axios
- **Export**: ExcelJS, File-saver

## نصب و راه‌اندازی

```bash
# نصب وابستگی‌ها
npm install

# اجرا در محیط توسعه
npm run dev

# ساخت برای تولید
npm run build

# اجرا در محیط تولید
npm start
```

## استفاده

1. انتخاب دسته‌بندی و زیردسته مورد نظر
2. مشاهده لیست محصولات و تحلیل‌های آماری
3. اعمال فیلترها و مرتب‌سازی
4. خروجی گرفتن به فرمت‌های مختلف
5. کپی اطلاعات محصولات یا دانلود تصاویر

## ویژگی‌های امنیتی

- Rate Limiting (جلوگیری از مسدود شدن)
- User-Agent Rotation
- Retry با Exponential Backoff
- احترام به robots.txt
